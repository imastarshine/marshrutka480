## Область выгрузки

Границы задаются как `west,south,east,north`: **104.06, 52.20, 104.45, 52.40**.
Это городская область с окрестностями и маршрутными коридорами, включая
Ново-Ленино, Батарейную и Луговое. Она не равнозначна административной границе
муниципалитета. Полные исходные дороги могут выходить за рамки области.

Снимок дорожной сети содержит границы, время получения, перечень источников
и статус полноты загрузки. Сохраняются исходные GPS-узлы и все дорожные теги;
здания и участки землепользования в этот набор не включаются.

Снимок от 11.11.2026 загружен полностью: **128 из 128 частей**, 164 052 исходных
узла, 36 627 объектов `highway` и 931 отношение ограничений. В исходник включены
также пешеходные и частные пути. После отбора дорог, доступных автобусу, и
объединения с маршрутными коридорами игровой граф содержит **38 885 узлов,
48 111 рёбер и 905 ограничений поворотов**. По обеим сторонам линий сохранены
297 остановочных записей; повторные проезды считаются отдельно.

## Обновление открытого снимка

```bash
python -m pip install requests
python scripts/download_irkutsk_roads.py
```

Загрузчик сначала делает один ограниченный запрос Overpass. Если сервис
недоступен, использует официальный OSM Map API с последовательной сеткой,
ограничением запросов и локальным кэшем в `test-results/osm-map-cache/`.
При повторном запуске готовые части читаются из кэша.

Готовая геометрия для игры создаётся импортером:

```bash
python scripts/import_irkutsk_osm.py
python scripts/export_traffic_graph.py
```

После изменения подтверждённых границ конечных обнови закреплённый кэш:
`python scripts/import_irkutsk_osm.py --refresh-route-cache`.
Обычный повторный импорт применяет те же правила, не добавляя лишние развороты.

Объединять дороги по близости координат запрещено в логике импорта:
соединение возникает только через общий исходный узел. Пропущенные участки
должны быть получены из источника, а не заменены прямой перемычкой.

Подробности сверки и границы точности: [источники Иркутска](../docs/IRKUTSK_SOURCES.md).
