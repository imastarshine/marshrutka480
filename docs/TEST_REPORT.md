## Сервер: 56 тестов — OK

```bash
cd server
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

Полный запуск: **56 tests, 27.532 s, OK**, Python 3.12.
Сохранены 51 проверка аккаунтов, хранения, HTTP/WS-ограничений, комнат,
переподключения и старой серверной симуляции arcade. Добавлены 5 тестов city:

- вход во время поездки, передача оригинальной модели, маршрута и гудка;
- строгая схема, запрет NaN/лишних полей, предел скорости и резких перемещений;
- сохранение положения и оформления игрока при переподключении;
- освобождение места и номера участника после выхода;
- отсутствие записи клиентских очков в рейтинг.

Хеши паролей, сессии, ограничения запросов, проверки Origin и Host,
изоляция комнат и закрытие недействительных соединений сохранены.

## Браузер: 8 интеграционных сценариев — OK

Google Chrome, Playwright, настоящий HTTP/WebSocket через Uvicorn.
Используются временная SQLite-база и два независимых контекста браузера.

1. Регистрация двух водителей через интерфейс, создание комнаты, поздний вход.
   Проверены исходный Game, сюжет и повороты, полная высота и центр холста
   на экране 1440×1000.
2. При задержке исходящих pose-пакетов на **350 мс** своя маршрутка начинает
   движение за **20 мс** (два локальных кадра в последнем запуске).
   Это проверка отсутствия ожидания сети, не обещание универсального времени отклика.
3. Второй клиент получает движение маршрутки, отображает её на исходной дороге
   и видит подписанную метку на миникарте.
4. Исходная анимация поворота передаёт направление и мировые координаты.
   Для этого сценария тест вызывает startTurn у ближайшего перекрёстка.
5. Имитированный обрыв WebSocket восстанавливает соединение и участие в комнате,
   сохраняя текущий локальный рейс.
6. Выход из комнаты сохраняет карьеру и позволяет продолжить поездку.
7. На телефоне 390×844 работают вертикальная прокрутка, хедер с профилем,
   сенсорные кнопки и ввод в форму без залипания управления.
8. В горизонтальной ориентации 844×390 нет горизонтального переполнения.
   Высокий экран 1280×1024 переключается на прокручиваемую страницу,
   чтобы боковое меню не перекрывало игру.

JavaScript-ошибок в консоли нет. Десктопный экран, диспетчерская и мобильная
страница проверены по снимкам. Сценарии и измерение записываются в
`test-results/city-browser-report.json`, снимки — в тот же игнорируемый каталог.

Повторить из корня (нужен установленный Google Chrome и свободный порт 18882):

```bash
python -m pip install -r requirements-browser.txt
python tests/browser_smoke.py
```
